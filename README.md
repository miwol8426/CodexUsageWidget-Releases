# Codex Usage Widget — 배포

Windows 10/11용 Codex 잔여 한도 위젯의 공식 배포 저장소다. 이 저장소에는 공개 배포 안내와 Releases 첨부파일만 제공한다.

[최신 버전 다운로드](https://github.com/miwol8426/CodexUsageWidget-Releases/releases/latest) · [소개 사이트](https://codexusagewidget.netlify.app)

ZIP에는 CodexUsageWidget.exe와 Pretendard-OFL.txt만 들어 있다. 압축을 풀고 EXE를 실행한다. .NET Framework 4.8 이상과 별도 설치한 Codex가 필요하다.

프로그램의 설정 또는 트레이 메뉴에서 업데이트를 확인할 수 있다. 1.10.0.0은 GitHub 연결 오류가 있어 1.10.1.0 이상을 한 번 직접 다운로드해야 한다. 이후 업데이트는 공개 버전 정보의 서명과 ZIP의 SHA-256을 검증한 뒤 적용한다.

업데이트는 위젯을 종료하고 다시 실행한다. 리셋권 예약 처리 중이거나 예약 시각이 가까우면 설치를 보류한다. 재시작 중 놓친 예약을 소급 실행하지 않는다.

미서명 Windows 실행 파일이다. 업데이트 파일의 검증 서명은 Windows 코드 서명과 다르며 Windows의 실행 허용을 보장하지 않는다.

소스코드, 개인 설정, 인증 정보, 진단 기록과 개발 이력은 이 저장소에 포함하지 않는다.
